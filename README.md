# せきがえ（席替えWEBアプリ）

小中学校の教室で使う席替えアプリです。ブラウザだけで動き、インストールやサーバーは不要です。
教室のテレビ・プロジェクターに映して、その場で席替えを発表できます。

## できること

- **名簿**：番号・名前・性別を登録。Excel からのコピー＆貼り付けや CSV 読み込みに対応
- **座席レイアウト**：列の数・1列の席数を設定。使わない席は「×」にできる
- **条件**
  - 前の方の席にする（前から◯列目まで）
  - 席を固定する
  - **離す**：2人のあいだを ◯席以上あける（1席＝となり・前後・ななめにしない）
  - **近づける**：2人を ◯席以内にする（1席以内＝となり・前後・ななめのどれか）
  - 男女交互（市松模様）
  - 前回と同じ席にしない／前回となりだった人ととなりにしない
- **席替え**：名前がシャッフルされる演出つきで発表。全画面表示（全画面中はスペースキーでもう一度）
- **手直し**：席を2つタップすると入れ替え。条件に合わなくなると注意を表示
- **印刷**：A4 横で座席表を印刷。「児童から見た図」「先生から見た図」を切り替え
- **履歴**：「この席で決定」で保存。次回の「前回と同じ席にしない」に使われる
- **保存**：データは端末のブラウザ内だけに保存。ファイルへの書き出し・読み込みで別の端末へ移せる

条件を満たす配置がないときは、どの条件をゆるめればよいかを表示します。

## 使い方

`index.html` をウェブサーバー経由で開きます（JavaScript モジュールを使うため、ファイルを直接ダブルクリックでは動きません）。

### GitHub Pages で公開する（おすすめ）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
3. 表示された URL を学校の端末で開く

### 手元のパソコンで試す

```sh
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 開発

外部ライブラリは使っていません（HTML / CSS / JavaScript のみ）。

```
index.html          画面
css/style.css       見た目（印刷用レイアウトを含む）
js/app.js           画面の動き
js/solver.js        席替えの計算（条件つきランダム配置）
js/layout.js        座席表の描画
js/roster.js        名簿の読み込み
js/storage.js       ブラウザへの保存・ファイル書き出し
tests/              solver のテスト
```

テスト（Node.js 18 以上）:

```sh
npm test
```
